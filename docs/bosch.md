## 🧪 Technical Round 1: Embedded Concepts & Protocols

**Focus Areas:**
- Bitwise operations
- Embedded C and memory types
- HIL (Hardware-in-the-Loop) Testing
- Communication protocols: CAN, SPI, LIN
- MISRA guidelines

**Sample Questions:**
1. Explain how you would use bitwise operations to:
   - Set a specific bit in a register
   - Clear a bit
   - Toggle a bit
   - Check if a bit is set

2. What is the use of `volatile` keyword in embedded C?

3. How do you ensure memory safety in embedded programming?

4. Explain the CAN protocol and the role of each field in the CAN frame.

5. What are the different types of memories in microcontrollers (RAM, Flash, EEPROM)?

## 💡 Technical Round 2: HIL Testing + Model-Based Design

**Focus Areas:**
- HIL test bench setup
- Vector tools (CANoe, CANalyzer)
- Integration testing at ECU level
- Usage of MATLAB/Simulink & Stateflow
- Fault injection and diagnostic simulation

**Sample Questions:**
1. Explain your experience with HIL testing. What tools did you use?

2. Describe a case where you wrote a test case for an input fault condition.

3. How do you simulate sensor inputs in HIL systems?

4. What are the different types of Stateflow charts? Why would you use Mealy vs. Moore?

5. How do you handle calibration and diagnostics in a model-based environment?
